# ausus 中古設備販売サイト

現場で発生した中古設備・未使用の余剰資材・自作品を販売するサイト。GitHub Pages（Jekyll）でホスティングする。
公開URL: https://toshiji39.github.io/ausus-shop/

## 商品の追加方法（コードは書かない）

商品は「1点＝1つのテキストファイル」。該当フォルダに新しいファイルを作り、以下の項目を埋めるだけで自動的にサイトに反映される。

- 即納パーツ（アングル・治具・未使用パイプ等、その場で購入） → `_komono/`
- 現物商談品（コンプレッサー・減速機等、中古の一点物・お問い合わせ） → `_omono/`
- 自作品（新品・購入 or 相談） → `_jisaku/`

即納パーツ・自作品の商品には `type:`（例: "アングル", "パイプ"）を指定すると、種類ごとの絞り込みボタンに自動的に反映される。

既存のファイル（例: `_komono/angle-l50.md`）をコピーして、中身を書き換えるのが一番早い。

```yaml
---
title: "商品名"
icon: angle              # アイコンの種類。_includes/icon.html にある名前から選ぶ
price: "2,400"           # カンマ区切りの文字列で（¥マークは付けない）
price_note: "税込"
payment_link: "https://buy.stripe.com/xxxx"   # Stripeの決済リンク。未設定なら空文字のままでOK（「準備中」表示になる）
specs:
  - label: "寸法"
    value: "50×50×5mm"
order: 10                # 表示順（小さい数字が先）
---
```

大物・お問い合わせ扱いにしたい商品は、`cta_type: inquiry` と `stock_note: "在庫あり・1台"` を追加する（`_omono/compressor-30hp.md` を参照）。

## 写真・図面PDFの追加方法

1. 写真ファイルを `assets/photos/` に、図面PDFを `assets/drawings/` に置く（GitHub上でドラッグ&ドロップでアップロード可能）
2. 商品のfront matterに以下を追加する

```yaml
photos:
  - "写真1.jpg"
  - "写真2.jpg"
  - "写真3.jpg"
drawing_pdf: "図面.pdf"
```

- `photos` は何枚でも追加できる（1枚だけでもOK）。商品カードの写真部分が横スクロールのギャラリーになり、2枚以上あると枚数バッジと矢印ボタン・ドットが表示される
- `drawing_pdf` を指定すると、商品情報の下に「図面PDFをダウンロード」というリンクが表示され、クリックでそのままダウンロードできる
- 実物写真ではなくイメージ写真を使う場合は `photo_is_stock: true` を付けると、写真の左上に「イメージ」バッジが出る
- どちらも省略可能。省略した場合は今まで通りアイコンのプレースホルダー表示になる

**注意: ファイル名の先頭にアンダースコア(`_`)を使わないこと。** Jekyllは`_`で始まるファイルを自動的に除外してしまい、サイトに反映されない（実際にこれで一度ハマった）。

## 出張・不在時の発送遅延のお知らせ

`_data/site_meta.yml` の `shipping_notice` に文言を入れると、サイト上部にオレンジの帯でお知らせが表示される（例:「担当者出張中のため、発送までに3営業日ほどいただく場合がございます」）。空文字に戻せば非表示になる。

## 準備が必要なもの（ユーザー側の作業）

1. **Stripe決済リンク**: 商品ごとに決済リンクを発行して `payment_link` に貼る（設定済み・運用中）。**リンク作成時、オプションの「顧客の住所を収集」を必ずONにすること**（配送先が分からなくなるため）
2. **お問い合わせフォーム**: Formspreeで作成し、`_data/site_meta.yml` の `inquiry_form_action` に設定する（設定済み・運用中）
3. **会社情報**: `_data/site_meta.yml` の特定商取引法表記・古物商許可番号を、取得・確定次第記入する（未設定）
4. **返品ポリシー・プライバシーポリシー**: 特定商取引法上、返品特約の表示が必須。会社情報確定と合わせて対応する（未設定。詳細は`company/research/reports/2026-09-01-ec-site-legal-checklist.md`）

会社情報が未設定の間は、サイト上部に「準備中」の通知バーが表示され、購入・問い合わせの送信もブロックされる。

## 送料について

小物・パイプ材料・自作品は送料込みの価格設定にする方針（Stripeの配送料別建て機能は使わない）。出品時の価格に送料の目安を上乗せすること（詳細は`company/finance/payment-options.md`）。
